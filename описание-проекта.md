# Сайт «Повелитель струн»

## Название
Сайт-визитка музыканта «Повелитель струн»

## Проблема
Музыканту нужна точка в интернете, которая показывает живые выступления, собирает доверие через отзывы и приводит к бронированию — и которую находят в поиске. Раньше заявки шли только через мессенджеры, без единой витрины.

## Пользователь
Люди в Краснодаре, которые ищут живую музыку на праздник — день рождения, корпоратив, камерную свадьбу, нетворкинг.

## Основная функция
Одностраничный сайт: показать музыканта (видео выступлений и отзывов), снять возражения (FAQ, цены) и привести к брони через Telegram.

## SEO-задача
Чтобы сайт находили в Яндексе по запросам «живая музыка / музыкант на праздник Краснодар»: title, meta description, Open Graph, микроразметка Schema.org, sitemap. Подключены Яндекс.Вебмастер, Метрика и Google Search Console.

## Формат результата
Живой сайт [povelitelstrun.ru](https://povelitelstrun.ru): адаптивный, быстрый, с встроенными видео (RuTube — работают без VPN).

## Что реализовано
- **Разделы:** hero со статистикой, видео выступлений, форматы, отзывы (видеоотзывы + скриншоты переписок из Telegram), об артисте, FAQ, блок бронирования
- **Навигация:** фиксированное меню с быстрыми переходами, плавная прокрутка, кнопка «Наверх»
- **Интерактив:** появление секций при прокрутке, анимированные счётчики цифр, ленивая загрузка видео, FAQ-аккордеон
- **Доступность:** поддержка «уменьшить движение» (prefers-reduced-motion), aria-метки, alt-тексты
- **SEO и аналитика:** title / meta / Open Graph, Schema.org (рейтинг, отзывы, FAQ, гео, услуги), sitemap, robots.txt, Яндекс.Метрика с вебвизором

## Технологии
- HTML / CSS / JavaScript (vanilla, без фреймворков)
- Schema.org (JSON-LD)
- RuTube (встроенные видео)
- Яндекс.Метрика
- Хостинг: Beget
